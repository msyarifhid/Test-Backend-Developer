## Test Backend Developer - Buat API untuk manajemen buku 
Instruksi Umum:
1. Buat aplikasi RESTful API menggunakan Express.js dan MariaDB.
2. Implementasi autentikasi menggunakan JWT (JSON Web Token).
3. Buat minimal 5 endpoint sesuai ketentuan.
4. Gunakan Jest.
5. Push di gitlab atau github.

Buat API untuk manajemen buku dengan fitur:
1. Autentikasi pengguna (register dan login).
2. CRUD Buku: Menambah, melihat, mengubah, dan menghapus buku.
3. Relasi: Setiap buku harus terhubung dengan tabel author.
4. Pagination: daftar buku.
5. Testing: Buat test case menggunakan Jest dan Supertest.

Testing - run in commend
- node server.js
- npm test
